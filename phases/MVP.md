# MVP Phase Plan

This file is a roadmap, not an execution queue.

Codex must not execute this file directly. GPT Project should convert one item at a time into `docs/TASK.md`.

## Phase 1: Project Setup

- Create Unity folder structure.
- Create main gameplay scene.
- Create initial Player object or prefab.

## Phase 2: Player Control

- Implement player movement.
- Implement mouse aim.
- Connect movement and aim through Unity MCP or Unity Editor.

## Phase 3: Combat Prototype

- Create weapon data.
- Create projectile logic.
- Create weapon firing logic.
- Connect FirePoint and projectile prefab.

## Phase 4: Enemy Prototype

- Create basic enemy movement.
- Create damage handling.
- Create basic enemy prefab.

## Phase 5: HUD

- Create health UI.
- Create basic wave or score UI.

## Rule

Each phase item must become a separate `docs/TASK.md` task before Codex executes it.
